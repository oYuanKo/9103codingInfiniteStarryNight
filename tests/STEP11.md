# Cosmic Threshold prototype

Enable/disable in the browser console: cosmicThresholdSettingsV2.enabled = true / false.
Default: enabled. No new keys or presentation controls. Disable for the accepted portal.

Run with Node + Playwright and installed Edge (BROWSER_CHANNEL may override):

    node tests/cosmic.browser.cjs
    node tests/refactor.browser.cjs

The cosmic suite captures matched paused-flow frames at 0, 20, 35, 45, 50, 55,
65, 80, 100 percent under tests/step11-on-*.png and step11-off-*.png.
It tests equal early/end pixels, same-resource reversal, actual wheel pause/reversal,
cache eviction/regeneration and paired frame costs including readback.
An optional ignored step11-original-shader.log from the pre-edit local shader enables
an additional same-browser disabled-versus-original comparison; it is not required
by fresh clones. The archived refactoring JSON fixture is not regenerated here.

Implementation: the original fragment program remains intact. A second program
on the SAME WebGL renderer reconstructs indigo pigment and delays silhouettes
between .35 and .88; the rest uses the original program. Existing brush ownership
and flow provide spatial variation. No extra texture, buffer, new noise or world.
A bounded cache (four entries, up to 48 curved paths each) samples child sky brush
positions and child flow directions using an independent deterministic hash of both
seeds and the entry star. Canvas 2D paints these sparse cream/gold/blue-grey marks,
with a thinner pigment ridge. They follow the unchanged child camera and gradually
fade into the arriving painting. No elapsed-time simulation, particles or bloom.
The cached paths retain no world/texture references. Regeneration after eviction
is deterministic. Only the portal draw call and shader selection are integrated;
Camera equations, graph, brush replay, micro LOD, hover and group API are unchanged.

Limitations: real curved geometry, but pigment/structure transport is still shader
reconstruction, not one-to-one parent/child stroke morphing. Marks borrow positions
and flow rather than exactly morphing into specific final strokes; fade is visible
if scrutinised. They do not receive the GPU cursor distortion themselves. Baseline
paint still responds to the cursor. Cosmic depth remains an artistic approximation.
PNG/WebM/log outputs are ignored. Tests prove invariants, not subjective naturalness.

## Local validation (Edge, 2026-10-15)

Matched 800x600 paused screenshots were inspected at all nine depths. In this moon
entry, 35% preserves large paint; 50% suppresses child silhouettes and adds sparse
curved pigment; 65% begins returning the child structures. Large parent shapes
remain perceptible. This is an experimental impression, not proof of visual success.

Steady paired frame/readback medians across four alternating batches: disabled
3.6–4.2 ms, enabled 3.6–4.1 ms; batch P95 5.2–8.9 / 6.3–7.5 ms respectively.
No reliable sustained overhead emerged in this run. These are CPU wall times with
GPU readback, not GPU timer queries or guaranteed interactive FPS. Geometry built
in about 0.2 ms (22 paths in the sampled entry). Seven-entry cache pressure ended
with four entries / 96 paths; the hard bound is four entries / 192 paths. Repeated
enabled/disabled draws kept seven renderer textures unchanged. A normal navigation
reset returned to one cached world, four graphics canvases and two textures.

The first experimental shader draw initially took about 152 ms. It now warms on
the first ordinary startup frame using the existing buffer, moving that one-time
compile cost out of the portal. After this change, first experimental portal use
was 6 ms, subsequent use 3.8 ms. Startup has an additional shader draw/compile;
this is not free. Initial shared child texture upload still costs time (the old
portal's first readback was about 51 ms in this measurement). No rendering settings
were changed to hide this cost.

Evidence: step11-on/off-{0,20,35,45,50,55,65,80,100}.png,
step11-comparison.png (left off, right on, depths in the above order),
step11-wheel-roundtrip.webm, step11-cosmic.log and step11-<suite>.log.
The full real-wheel recording is generated by the existing spatial suite and copied
to the Step 11 filename. Original-shader comparison passed at every sampled depth;
0–35% and 100% on/off matched exactly in this browser. Existing suites also exercise
other entry positions, multiple levels, Outer return, cursor locality and shortcuts.
